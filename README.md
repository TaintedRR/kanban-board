# Канбан-доска · Kanban Board

Доска задач в стиле Trello: три колонки, перетаскивание карточек, приоритеты, поиск и прогресс выполнения.

**Демо:** https://taintedrr.github.io/kanban-board/

## Возможности

- Колонки «Нужно сделать», «В работе» и «Готово» со счётчиками задач.
- Перетаскивание карточек мышью (HTML5 Drag and Drop) с подсветкой места вставки.
- Кнопки-стрелки для перемещения на телефоне и с клавиатуры.
- Двойной клик по названию переименовывает задачу. Enter сохраняет, Esc отменяет.
- Приоритет меняется кликом по метке: низкий, средний, высокий.
- Поиск по задачам и полоса прогресса «N из M готово».
- Удаление с подтверждением прямо на карточке.
- Интерфейс на русском и английском, переключатель RU / EN в шапке.
- Доска сохраняется в `localStorage` и переживает перезагрузку.
- Светлая и тёмная тема, адаптив под телефон.

## Технологии

HTML, CSS, JavaScript без библиотек: Drag and Drop API, `contenteditable`, `localStorage`.

## Запуск

Открой `index.html` в браузере. Сборка не нужна.

## English

A Trello-style task board with three columns, drag and drop, priorities, search and progress.

- Drag cards between columns or move them with the arrow buttons.
- Double-click a title to rename it, click the label to change priority.
- Search, a progress bar and delete with confirmation.
- Russian and English interface with an RU / EN switch, light and dark themes.
- Plain HTML, CSS and JavaScript, saved in `localStorage`. Open `index.html` to run it.
